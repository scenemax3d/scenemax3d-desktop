# Built-in MCP Server and AI Assistants

The Rust IDE exposes project editing, scene and UI authoring, validation, and preview tools through its local MCP server. Connect over HTTP or use the native `scenemax_mcp_proxy` executable for stdio clients. The old JAR proxy is not used.

See the [current guide](../scenemax3d_nextgen/IDE/MCP.md) for setup, supported features, and limitations.

See also [Web publishing](../scenemax3d_nextgen/IDE/WEB_EXPORT.md), [multiplayer](multiplayer.md), and the [documentation index](README.md).
