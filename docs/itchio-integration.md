# itch.io Publishing

Open Tools → Package & Deploy to configure your game page and platform channels. Sign in with Butler, build the selected targets, then upload automatically or retry an existing build. Windows and Web exports use bundled runtimes. Web ZIPs can also be uploaded manually as browser-playable HTML games.

See the [current guide](../scenemax3d_nextgen/IDE/DEPLOYMENT.md) for setup, supported features, and limitations.

See also [Web publishing](../scenemax3d_nextgen/IDE/WEB_EXPORT.md), [multiplayer](multiplayer.md), and the [documentation index](README.md).
