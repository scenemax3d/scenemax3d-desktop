# Model Animation Analyzer

Create named frame ranges from registered glTF/GLB animations, preview and scrub playback, and save the ranges as project catalog metadata. Model conversion and optimization are available through Import 3D Model; the analyzer does not export J3O files.

See the [current guide](../scenemax3d_nextgen/IDE/ANIMATION_ANALYZER.md) for setup, supported features, and limitations.

See also [Web publishing](../scenemax3d_nextgen/IDE/WEB_EXPORT.md), [multiplayer](multiplayer.md), and the [documentation index](README.md).
